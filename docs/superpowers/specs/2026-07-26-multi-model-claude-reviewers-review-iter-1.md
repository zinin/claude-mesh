### [CR-2] `claude_models` принимает пустую строку в обход проверки членства

> codex: элемент читается через `jq -r` и сверяется как строка, нет проверки `type == "string"`.
> qwen: `[null]` даёт дезориентирующее `unknown claude model "null"`, нужен `[ -n "$cmv" ]`.

**Источник:** codex + alibaba/qwen (независимо, с разных сторон); усилено `review-discussion` живыми jq-пробами
**Статус:** Автоисправлено
**Ответ:** Дефект сильнее, чем описали оба ревьюера, и воспроизведён напрямую. `tr '\n' ' '` оставляет `$claude_catalog` равным одному пробелу при отсутствующем каталоге, поэтому `" $claude_catalog "` — это `"  "`, и glob пустого `$cmv` с ней **матчится**: элемент `""` проходит проверку членства даже когда каталога нет вообще. Нестроковые `5` / `true` проходят тем же путём. В `validate_models` соответствующий guard (`[ -n "$id" ] || die`) есть — новый цикл его терял.
**Действие:** В план добавлен type-gate элемента и `[ -n "$cmv" ]` **до** проверки членства, с объяснением порядка. В Test 48 добавлены кейсы на нестроковые элементы и на пустую строку. В дизайн §5.2 добавлены две строки таблицы.

### [IM-1] Порядок вызова `validate_claude` расходится с дизайном

> Дизайн §5.2 требует «первым делом», план ставит вызов после early-return по `.defaults`.

**Источник:** codex
**Статус:** Авто-применено после анализа
**Ответ:** Вариант B — привести дизайн в соответствие с реализацией. Решающим оказался прецедент: `validate_defaults` уже ссылается на `.models`, но `validate_models` не вызывает, и это зафиксировано комментарием в `config-loader.sh`. Эмпирически подтверждено, что `get-defaults` на `models: false` без `defaults:` возвращает пустой пресет с rc=0 — то есть ровно та же «дыра» для `models:` уже считается нормой. Делать `claude:` строже было бы необъяснимой асимметрией.
**Действие:** §5.2 переписан: вызов «сразу после проверки наличия `.defaults`», с объяснением настоящей причины (`.models` прикрыт оператором `//`, а `(.claude.models // [])` сначала индексирует `.claude` и падает на скаляре) и перечислением команд, которые ловят битую секцию.
